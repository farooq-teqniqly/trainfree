# Implement skeleton loading screen

When Programs with many sessions load, there is a noticeable delay where nothing is displayed. It would be a better visual and user experience to display a skeleton loading screen with a shimmer effect. This also happens to a lesser extent on Phases and Exercises. 

Suggest to build a reusable component that can be shared in the Admin and to be implemented Workout apps. Ideally, no 3rd party libraries should be used aside from Bootstrap.
