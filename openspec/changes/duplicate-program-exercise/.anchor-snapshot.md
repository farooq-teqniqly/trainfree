# Implement a Duplicate Exercise functionality

When adding Exercises to Sessions, I often create the same exercise multiple times that differ by side (see dumbbell front rack split squat image). It would be faster if I could duplicate the first entry repeatedly.

<img width="1508" height="593" alt="Image" src="https://github.com/user-attachments/assets/cd6aab71-f04a-4de0-97e7-b9f4900c5400" />

**Scope for this issue: single-row duplicate only.**

Add a duplicate action per program-exercise row (icon button alongside Save/Revert/Delete). Duplicating clones the exercise, reps/duration, sets, rest, weight, and side onto a new row appended to the end of the phase's exercise list (no reorder/position feature exists yet, so it lands at the bottom, not next to the original). You then flip Side (or any other field) on the new row as needed.

The multi-select group duplicate (see the repeated side plank abduction / prone frog kick group example) is split out to #108 -- it needs row multi-select UI and a bulk action, which is a bigger slice than this one.
